# ChurnShield

**An Explainable Customer Retention Intelligence System**

## Overview

ChurnShield is a data analytics and machine learning project designed to analyze customer churn, predict customers at risk of leaving, and support data-driven retention decisions.

## Day 1 Progress

* Created the project directory structure.
* Set up a Python virtual environment and installed the required libraries.
* Loaded and inspected the Telco Customer Churn dataset.
* Removed duplicate rows and cleaned the churn target.
* Converted `TotalCharges` into a numerical column.
* Exported the cleaned dataset for further analysis.

## Technology Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SQLite, Power BI.
